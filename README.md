# Advanced Inventory Management System (AIMS)

A professional full-stack Inventory Management System built using FastAPI, React, MongoDB Atlas, and JWT Authentication.

## Features

- User Authentication (JWT)
- Role-Based Access Control (RBAC)
- Product Management
- Category Management
- Inventory Tracking
- Purchase Orders
- Sales Orders
- Supplier Management
- Dashboard & Reports
- Low Stock Alerts

## Tech Stack

### Backend
- FastAPI
- PyMongo
- MongoDB Atlas
- JWT Authentication
- Passlib (bcrypt)
- Pydantic

### Frontend
- React
- Vite
- Tailwind CSS
- Axios
